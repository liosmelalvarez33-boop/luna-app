# Luna - Tu Ciclo 🌙💜

Una aplicación PWA hermosa y funcional para el seguimiento menstrual, con predicciones, síntomas y estadísticas.

## ✨ Características

### 📅 **Calendario Interactivos**
- Visualización mensual con navegación
- Días de período: gradiente rosa→morado con animación de pulso
- Ventana fértil: destacada en morado brillante
- Día actual: anillo pulsante que atrae la mirada
- Leyenda visual integrada

### 🔮 **Predicciones Inteligentes**
- Estimación del próximo período
- Ventana fértil y ovulación
- Representación visual del ciclo
- Consejitos personalizados según fase

### 💝 **Registro de Síntomas**
- 8 síntomas comunes (cólicos, hinchazón, dolor de cabeza, etc.)
- Escala de intensidad (1-5) con colores dinámicos
- Notas personalizadas
- Registro de síntomas diarios

### 📊 **Estadísticas**
- Promedio de ciclo y período
- Síntomas más frecuentes con barras progresivas
- Racha actual (streak) con animación de fuego 🔥
- Exportación a CSV
- Consejos basados en tus datos

### ⚙️ **Configuración**
- Personalización de longitud de ciclo y período
- Tema oscuro/claro automático
- Recordatorios/notificaciones
- Notificaciones push 2 días antes del período

### 📱 **PWA Completa**
- Instalable en dispositivo móvil
- Funciona offline
- Icono de pantalla de inicio
- Diseño responsive

### 🌟 **Animaciones Premium**
- Fondo de partículas brillantes
- Glassmorphism en tarjetas
- Animaciones de aparición escalonada
- Botones con efecto "shine"
- Iconos con efecto flotar
- Barras de progreso con efecto shimmer

### 🔗 **Compartir**
- Compartir app con amigas
- Exportar datos a CSV

## 🚀 Tecnologías

- **React 19** + Vite
- **Vite PWA Plugin** - para la funcionalidad PWA
- **react-icons** - iconografía
- **date-fns** - manejo de fechas en español
- **localforage** - almacenamiento local persistente

## 🎨 Tema

**Morado Profundo** con:
- Gradientes elegantes: `#c77dff → #ff6b9d`
- Glassmorphism moderno
- Partículas animadas en fondo
- Modo claro opcional

## 📦 Instalación

```bash
git clone [repo]
cd period-app
npm install
npm run dev
```

## 🔧 Build para Producción

```bash
npm run build
```

## 💡 Uso

1. Marca tu primer día en el calendario
2. Registra tus síntomas diariamente
3. Consulta las predicciones
4. Revisa las estadísticas
5. ¡Comparte con tu círculo más cercano!

## 📱 PWA Install

Puedes instalar la app en tu teléfono:
- **Safari**: Compartir > "Añadir a pantalla de inicio"
- **Chrome**: Menú > "Instalar Luna"
